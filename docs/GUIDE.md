# Campaign Pocketbook guide

The full user guide and developer notes. For a short introduction and how to install, see the [README](../README.md).

## Updating
If you cloned with Git, double-click **`update.bat`** (or run `git pull`) to get the latest version, then start the app as normal - it rebuilds itself automatically. Your campaigns are not affected by updates.

The app also checks GitHub when it starts (only needs an internet connection; it stays silent if offline). If a newer version number is published, a blue banner appears at the top with an **Update now** button (git copies) or a link to the download page (ZIP copies).

## Where your data lives
Projects are saved as plain files in `~/CampaignPocketbook/<project name>/` (`project.json`, then a folder per kind of item: `boards/`, `maps/`, `cards/`, `spells/`, `items/`, `quests/`, `sessions/`, `encounters/`, plus `images/` and `assets/`). Everything autosaves. To reorder the project tree, drag an item onto a folder to put it inside, or between two items (a blue line shows where it will land) to place it exactly; or select one and press **Alt+Up** / **Alt+Down** (or right-click > **Move up** / **Move down**) to move it among the items in the same folder. (The app used to be called D&D Campaign Notes and kept its files in `~/DnDCampaignNotes`; the first time the new version starts it moves that folder to the new name, so nothing is lost.) If something goes wrong the app writes the details to `~/CampaignPocketbook/app.log` (about 1 MB, plus the previous file); send that file along when reporting a problem. To back up or move a campaign, copy its folder, or use **Export backup...** on the project list (see "Backing up and sharing a campaign" below).

## Using it
The toolbars (whiteboard, battlemap and the top bar) use small icons to stay uncluttered. **Hover any icon** to see its name, what it does and its shortcut key; the tool icons keep their number keys (1 to 0), and switches such as Name hints, Link previews, Grid, Snap and Fog show as pressed (highlighted) when they are on. The buttons above the project tree are icons too: each shows the icon of the kind of item it creates with a small green plus (hover one for its name). This guide still calls them **+ Board**, **+ Battlemap**, **+ Card**, **+ World map** and so on.

The **top bar**, left to right: house = Projects (back to the campaign list), arrows = Back / Forward, the path of the item you have open, then three **dropdown buttons** (an icon with a small arrow; click one and a list opens with an icon and a name on each row, and the key where there is one): dice = **Generators** (**Names...**, **NPC...**, **Loot...**), book = **Reference** (**Rules...**, **Library...**, **Relations...**, **Quests...**, **Timeline...**), clock = **History** (**Recent** items and **Backlinks**); then sun / moon = light or dark mode, the gear = **Settings**, and the search box. The rest of this guide refers to the entries by those names.

The whiteboard, battlemap and world map toolbars work the same way: the tools, colours and undo / redo stay in view, and the rest is grouped into dropdowns (whiteboard: **Insert**, **Line width and filled shapes**, **Links and notes**; battlemap: **View** for the grid, snapping and fit; world map: **View** for grid, scale bar, legend, relief shading, snapping and fit, **Links and hiding**, **Players** and **Map** for art style, season and year, travel speeds, generate and resize). Switches in a dropdown show a tick when they are on.

**Resizing panels.** Drag the thin edge between two panels to make one wider or narrower: the project tree, the piece library and symbol panel beside a map, the creature cards and turn-order strip of a battle, the lists in the Library, NPC and Common enemies windows, and the form / preview split of each editor. Your sizes are remembered, and **Settings > General > Reset panel sizes** puts them all back.

| Do this | How |
|---------|-----|
| Open a board | Double-click it in the project tree (left). Right-click the tree to add, rename or delete; drag to move. |
| Curve a line or arrow | Select it: a round handle sits on the line, next to the square end handle. Drag the round handle sideways to bend the line into a curve, and drag it along the line to move where it bends. Pull it back onto the line to straighten it. The arrow head follows the curve. |
| Add text | Double-click empty space (or the Text tool). Ctrl+Enter, Esc or clicking away finishes. |
| Text box with a set width | With the Text tool, **drag out a box** instead of clicking. Text wraps onto the next line when it reaches the box edge, and the box gets taller or shorter by itself as you type. Drag the small square at its bottom-right corner to change the width at any time, including **while you are typing** (double-click a text and resize straight away); the words reflow as you drag. Right-click > **Fit width to text** puts it back to one automatic-width block. A plain click (or double-click on empty space) still makes a text that takes the width of what you type. |
| Pan / zoom | Hand tool, middle-mouse drag, or hold Space and drag. Mouse wheel zooms; Ctrl+0 fits everything in view, Ctrl+1 is actual size, Ctrl+= and Ctrl+- zoom in and out. |
| Link to another board | Select an object, press **Link...** (Ctrl+K or right-click), pick a board. Double-click it to jump. Blue badge = linked, red = target was deleted. |
| Go back | Back/Forward buttons or Alt+Left / Alt+Right. The trail shows where you came from. |
| See what links here | **History > Backlinks** at the top. |
| Search | Box at the top right (Ctrl+F). Finds text on whiteboards (including hover notes) and map pins, and inside cards (traits, actions, attacks, notes, relationship notes), spells, magic items, quests (summary, steps, giver), session logs (recap, what happened, next steps) and encounters (names and notes). Press Enter to search again; the results update as you type. |
| Bold / italic words | While typing in a text or sticky note, **select some words** and press **Ctrl+B** / **Ctrl+I** (or the **B** / **I** toolbar buttons). Press again to remove. Outside of typing, the same buttons make the whole text or sticky note bold or italic. |
| Images | **Image...** button, paste with Ctrl+V, or drag files onto the board. |
| Undo / redo | Ctrl+Z / Ctrl+Y |
| Copy / paste / duplicate | Ctrl+C / Ctrl+V / Ctrl+D (works between tabs) |

Styled words are saved as simple markup inside the text: `**bold**`, `*italic*` and `***both***`. While you are typing you see those marks around the words; once you finish, the board shows real bold and italic. A literal `*` that would be mistaken for formatting can be typed as `\*`. Search matches the words, ignoring the marks.

### Keyboard shortcuts

One rule: **Ctrl+letter acts on what you are editing, and a few Ctrl keys open the app's own windows.** The same keys work on whiteboards, battlemaps and world maps, whichever part of the tab you last clicked.

| Keys | What it does |
|---|---|
| Alt+Left / Alt+Right | Back / forward through the items you opened |
| Ctrl+W, Ctrl+F | Close the tab, search the campaign |
| Ctrl+G, Ctrl+L, Ctrl+Shift+N, Ctrl+R | Name generator, loot generator, NPC generator, quick reference |
| Ctrl+, | Settings |
| Ctrl+Z, Ctrl+Y (or Ctrl+Shift+Z) | Undo, redo |
| Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+D, Ctrl+A | Copy, cut, paste, duplicate, select all (on all three kinds of map and board) |
| **Ctrl+K** | **Link and note** the selected thing (whiteboard objects and words, world map items, battlemap tokens and pieces) |
| Delete or Backspace, Esc | Delete the selection, deselect or cancel |
| Ctrl+0, Ctrl+1, Ctrl+= / Ctrl+- | Fit everything, actual size, zoom |
| [ and ], F, H | Rotate, flip, hide from players (battlemaps and world maps) |
| Enter or F2 | Edit the selected text, or finish the line you are drawing |
| N, P | Next / previous turn during a battle |
| 1 to 9, 0 | Pick the tools in order, as described below. On world maps **B** is Bucket, **R** Reveal and **E** Elevation |

**Changing the keys.** Open **Settings** (the gear in the top bar, or Ctrl+,) and go to the **Shortcuts** tab. Click the key of an action, then press the keys you want instead (Esc cancels); **+** gives an action a second key, **x** takes a key away, and **Reset** puts one back (or **Reset all shortcuts**). The same key may be used for different things in different editors, but if it is already used for something that can happen at the same time you are asked whether to take it from the other action, which is then left without a key (listed in red until you give it one). Search the list by action or key. Your choices are part of your settings, so they travel with a settings file.

While you type in a text box, only the Ctrl and Alt shortcuts that open windows or move between tabs work, so typing is never stolen. Every key is shown in the tooltip of its button.

### Tool shortcuts
Press a number key to switch tools: **1** Select, **2** Hand, **3** Text, **4** Sticky, **5** Pen, **6** Eraser, **7** Rect, **8** Ellipse, **9** Line, **0** Arrow. The eraser only removes pen drawings.

## Battlemaps
Battlemaps are a separate item type next to whiteboards, saved as `maps/<id>.battlemap` in your project folder.

- **Create one:** **+ Battlemap** in the project tree (or right-click > New battlemap). Choose **Squares** or **Hexagons**, the map size in cells, and the cell size.
- **Resize it later:** **View > Map size...** (the grid icon in the toolbar). Add rows and columns on any side, or type a negative number to cut that many off; terrain, revealed fog, tokens, pieces, pins and lights keep their place on the map, and anything that ends up outside is removed. Tokens are never removed: if a crop would cut one off you are told and nothing changes (move the token first). On a hex map, rows are added to or cut from the top two at a time so the hexes line up. You can also change the **cell size**: pieces, pins and lights grow or shrink with it. A resize is one step of **undo**.
- **Side panel of pieces:** 150+ detailed built-in vector pieces in seven categories: **Buildings** (houses, tavern, windmill, chapel, keep...), **Walls** (stone, gates, palisades, hedges, doors, interior walls), **Paths** (dirt and cobbled roads, bridges, stairs, rivers), **Camp** (tents, fires, wagons, boats, tools), **Nature** (trees, bushes, rocks, ponds, mushrooms, crystals), **Dungeon** (pillars, altars, traps, portals, summoning circles) and **Furniture** (beds, tables, rugs, fireplaces, bookshelves). Click a piece, then click the map to place it as often as you like (Esc to stop), or drag it onto the map. **Import SVG / PNG...** adds your own pieces; they are copied into the project's `assets` folder.
- **Tools** (number keys 1-9 and 0): Select, Hand, Terrain, Piece, Token, Ruler, Fog, Area, Pin, Light. The toolbar only shows the settings of the tool you have selected (terrain and brush for Terrain, the fog controls for Fog, shape and size for Area, light kind and Dark map for Light, and so on), so it stays tidy; The **View** dropdown (Grid, Snap, Fit) and the buttons on the right are always there.
  - **Terrain:** paint grass, dirt, sand, stone, wood, water, snow or lava onto cells. Each is a textured ground type (grass blades, pebbly dirt, flagstones, wooden planks, rippling water, cracked lava...) that flows continuously across cells, with soft irregular edges where two types meet. Drag to paint, choose *Erase* to clear, change the brush size.
  - **Select:** move pieces (with **Snap** they line up with the grid), drag the round handle to rotate in 15 degree steps (hold Alt for free rotation), drag the square corner to resize (hold Shift to stretch). `[` / `]` rotate, `F` flips, right-click for front/back, copy, duplicate and delete.
  - **Selecting:** click a piece or token (clicking a transparent corner of a piece picks whatever is underneath). **Ctrl+click** (or Shift+click) adds or removes exactly that item from the selection; Ctrl+drag a box to add everything inside it; Ctrl+A selects all.
  - **Copy / paste:** Ctrl+C, Ctrl+X, Ctrl+V and Ctrl+D (duplicate) work on pieces and tokens, including between maps, and keep working when you have just used the toolbar.
  - **Token:** click a cell for a coloured token; double-click it to rename; right-click to set its size (medium to gargantuan).
  - **Ruler:** drag to measure distance in cells and feet (5 ft per cell). The measurement stays on the map until you measure again, press Esc or press Clear. Turn on **Show players** (the monitor icon) to draw it in the player window too.
- **Pop out for the players:** the **Pop out** button on a map opens it in its own window showing just the map (no handles or tool clutter). Drag that window to your playtable monitor and press **F11** for fullscreen. It updates live as you edit and has its own camera, so zooming it never moves your view. In that window: scroll to zoom, drag to pan, **F** or double-click to fit, **G** toggles the grid, **+/-** zoom. It remembers which monitor it was on, and closes when you leave the project or delete the map.
- **Preview on a whiteboard:** on a whiteboard open the **Insert** dropdown and choose **Preview of an item** (or right-click > Insert item preview...), then pick any item of the project: a battlemap, a world map, a character or monster card, a spell, a magic item, a quest, a session, an organisation, an encounter or another whiteboard. A map shows as a live thumbnail with its name; everything else shows as its card (the same card you see when you hover a link to it). It updates when you edit the item; resize it with the corner handle, and **double-click it to open the item**. Previews also show up in Backlinks. (A whiteboard cannot preview itself.)
  - **Area** (key 8): lay a spell or breath area over the map. Pick **Circle (burst)**, **Cone**, **Line** or **Cube** and a size in feet in the toolbar, click where it starts and drag to aim it (15 degree steps, hold Alt for free aim; a circle follows the pointer). The cells it covers are tinted and counted ("30 ft cone: 19 cells"). A cell counts when its centre is inside the shape, on square and hex grids. Turn on **Show players** (the monitor icon) to draw it in the player window too. **Clear area** or Esc removes it. It is a temporary overlay and is not saved.
  - **Pin** (key 9): numbered notes for you alone, never shown to the players: a trap, a secret door, what a monster does. Click the map to add one, click a pin to move it, double-click (or right-click > Edit) to change its note, and optionally **link it to a whiteboard, card or encounter** that you can open from the pin. Hover a pin to read its note. Pins are included in project search and in undo.
  - **Light** (key 0) and **Dark map:** turn on **Dark map** (the moon icon) and the map is dark: cells that no light reaches are black-blue in the player window, dim-lit cells are shaded, and bright cells are clear (you see a lighter version so you can still edit). Place light sources with the Light tool (Candle 5/10 ft, Lamp 15/30, Torch 20/40, Campfire 20/40, Lantern 30/60, Daylight spell 60/120: bright light, then dim light). Drag a light to move it, right-click to remove it. Right-click a token for **Carries a light** (it moves with the token) and **Sees in the dark (darkvision)**: darkvision treats darkness as dim light and dim light as bright light within its range. With fog on, a token's darkvision and carried light also clear the fog around it as it moves. There are no walls for light to stop at: it is a plain radius.
  - **Hidden pieces:** right-click a piece or token > *Hide from players* keeps it (a trap, an ambusher) out of the player window; it shows ghosted for you.
- **Links and notes on pieces.** Any token or piece (a door, a statue, a house) can carry a **note** and a **link** to a whiteboard, card, battlemap, quest, session, spell, magic item, encounter or a world map. Right-click it and choose **Link and note...**. With the Select or Hand tool, pieces with a note or link show a small dot (blue for a link, green for a note), hovering one shows the note above a preview of what it links to, **double-click a piece** to open its link, and right-click > **Open linked item** works for tokens too (double-clicking a token still renames it). Notes and links are for you alone: the player window never shows them. They are included in undo, project search and the Backlinks list. World map symbols, lines and regions can be linked the same way (see World maps).
- Map names, token labels and pin notes are included in project search. Undo/redo, copy/paste and autosave work like on whiteboards.

## World maps
World maps are their own item type (**+ World map** in the project tree, saved as `worldmaps/<id>.worldmap`) for whole continents and worlds. Create one by choosing a size (small, medium or large), how many miles it is across, and an **art style**. You paint freehand with a round brush: the **Land and sea** tool paints **ocean, lakes, land, lava and ice** (and an eraser), and the **Biomes** tool paints what covers the land: grassland, plains, farmland, forest floor, jungle, savanna, sand, desert dunes, badlands, rock, snow, tundra, swamp, moorland and volcanic ash (biomes only go on land and ice). Coastlines are drawn smoothly and raggedly, not blocky, and the brush width is in map cells. The mouse wheel zooms, the hand tool (or the middle mouse button, or Space) pans, **Fit** shows the whole map, and undo / redo (Ctrl+Z / Ctrl+Y) take back whole strokes.

There are five art styles, and you can switch between them at any time without repainting: **Classic ink** (sepia on parchment with water lines along the coasts), **Watercolour** (soft washes), **Fantasy colour** (bold colour, shaded shallows and foamy shores), **Retro pixel** (chunky pixels and a limited palette) and **Dark fantasy** (dim land under black seas). The status line under the map shows where the pointer is in miles.

**Symbols.** The side panel holds a library of map symbols, each drawn in all five art styles, grouped as mountains and hills (peaks, ranges, snowy mountains, mesas, hills, cliffs, volcanoes that are dormant, smoking or erupting), forests (oak, birch, pine, jungle, palm, dead, enchanted and mushroom trees, mangroves, and whole forests), water (lakes, ponds, waterfalls, oases, whirlpools, reefs, islets, icebergs), caves and holes (caves, craters, canyons, sinkholes, ice caves, lava vents, geysers), desert, arctic and swamp (dunes, cacti, glaciers, reeds, bogs, grass) and landmarks (towers, ruins, temples, obelisks, standing stones, bridges, lighthouses, mines, dungeon entrances, portals, shipwrecks, battlefields, graveyards, camps, statues, ancient trees). Search them or pick a group. Choosing a symbol arms the **Stamp** tool (click to place one, as often as you like; Esc puts it away) and the **Scatter** tool, which paints a whole forest, range of hills or mountains with the brush: the symbols are spread out so they do not pile on top of each other, mix the kinds in the same family, vary a little in size, and stay off the sea. The **Size** box sets how wide placed symbols are in map cells (0 uses each symbol's own size) and **Density** how thickly Scatter plants.

The **Bucket** tool fills a whole area in one click: pick Ocean, Land or another terrain (or a biome) next to it and click the sea, a lake or a continent; it fills everything connected that is the same as where you clicked, and undo takes it back in one step. Resizing a symbol also sets the **Size** box, so symbols you place afterwards come out that size until you change it again.

The **Select** tool picks symbols (click, shift-click, or drag a box over empty map), moves them by dragging, resizes a single one with the square at its corner, **[** and **]** turn it 15 degrees, **F** flips it, **Delete** removes it and Ctrl+D duplicates it. Symbols nearer the bottom of the map are drawn in front. Each symbol can have its own art style (the style box in the toolbar), so a classic-ink castle can stand on a watercolour map. Everything is undoable.

**Rivers, roads, borders and regions.** The **Lines** tool draws a **river** (thin at its source, wider towards its mouth), **road**, **trail** (dashed), **sea route** (dotted), **border** (dash and dot) or **railway** (with ties): drag to draw freehand (the line is tidied up when you let go), or click point by point and double-click (or press Enter) to finish; Backspace takes back the last point and Esc cancels. Lines are drawn as smooth curves through their points, in the map's art style (or their own), and the width can be set. With the **Select** tool click a line to select it: drag its points to reshape it, double-click the line to add a point, Alt-click a point to remove it, change its kind or width in the toolbar, or press Delete. The **Region** tool outlines a named area (a kingdom, a forest, a sea): click the corners, double-click to close it and type its name; it is softly tinted with a dashed border and its name written across it. Double-click a selected region to rename it (if it has a link, double-click opens the link instead, and right-click > **Rename...** renames it); cancelling or clicking away from the name box keeps the old name. Select a region and drag the orange diamond to move its name, for instance off a city drawn in the middle of it.

**Settlements, decorations and banners.** The same side panel has **settlements** from a lone cottage through hamlet, village, town, walled town, city and capital to port, fortress, castle, monastery, watchtower and ruined city, plus elven, dwarven and orcish holds; **decorations** (compass roses, a wind rose, a north arrow, a kraken, sea serpent, whale, giant crab, sailing ship, longship, dragon, anchor, flourishes, dividers and corner pieces); and **banners** (scroll, ribbon, plaque, cartouche, hanging banner, heraldic shield). A banner asks what it should say when you place it and fits the words to its shape; double-click it with the Select tool to change them.

**Labels.** The **Label** tool writes a name on the map: click, type the words, done. Choose the kind next to the tool (map title, region name, sea or lake, town, river or mountain, small note), which sets the size, letter spacing and look, and the **Curve** to make the words follow an arc, as along a coast or around a bay. Labels are drawn in the map's art style with a soft halo so they stay readable over any terrain. With the Select tool they move, turn, resize (the square at the corner) and copy like symbols; double-click one to change its words, and with one selected, changing the kind or curve in the toolbar changes it.

**Grid, scale, legend and travel times.** The toolbar can lay a **square or hex grid** over the map (you set its size in miles; hexes are measured across their flat sides) and write the name of each cell (A1, B1...), which also shows in the status bar under the cursor. The **scale bar** shows a round distance and can be turned off; the **legend** builds itself from the symbols and kinds of line you have used, and you drag it with the Select tool to where you want it. The **Ruler** tool measures a journey: click points along the way and it shows the total distance and how long it takes on foot (slow, normal and fast), riding, by sailing ship and by longship, counting 8 hours of travel a day. Esc clears it, Backspace takes back a point. **Map > Travel speeds** sets how many miles a day each way of travelling covers (the defaults follow the 5th edition rules: 18, 24 and 30 miles on foot).

**Links and notes.** Any symbol, settlement, label, banner, line or region can carry a **note** and a **link** to a whiteboard, card, battlemap, quest, session, spell, magic item, encounter or another world map (zoom into a region by linking it to a more detailed map). Select it and press the link button (or Ctrl+K), or right-click it and choose **Link and note...**. Things with a note or link show a small dot: blue for a link, green for a note. **Hover** one and the note appears above a preview of what it links to; **double-click** it (with the Select or Hand tool) to open the link, and the right-click menu has **Open linked item**. The eye button turns the previews off (the same setting as on the whiteboards). The **Backlinks** button in the top bar lists the map items that link to the item you have open, and clicking one jumps to it on the map. Project search also finds labels, names of lines and regions, and notes on world maps.

**Elevation and relief.** The **Elevation** tool paints how high the land is. Choose what the brush does: **Raise** or **Lower** the land a little with every stroke (stroke again and again to build a mountain), **Smooth** it out, or **Flatten** it to a chosen height (0 is flat, 255 the highest peak). **Strength** is how much each stroke changes. The height is shown as **relief shading**: light on slopes facing the top left and shadow on the others, drawn in the way of each art style (hachure strokes in classic ink, soft washes in watercolour, strong shade in fantasy and dark fantasy, three flat tones in retro pixel). The relief button turns the shading on and off, **Shading** sets how strong it is, and **Flatten all** sets the whole map back to flat (you can undo it). Maps with no elevation look exactly as before; the height also follows the map when you scale or crop it.

**Random worlds.** Tick **Generate a random world** when you create a map (or press the dice button on an existing one) to start from a finished world instead of a blank sheet. It makes continents and seas, mountain ranges (as elevation, so relief shading works), lakes, **biomes by temperature and rainfall** (snow and tundra at the cold edges, desert and jungle in the heat, forest and grassland between, beaches along the coast), **rivers that run downhill** from the hills to the sea or a lake, mountains, hills, forests and towns of several sizes, and **place names** for the seas, kingdoms, mountains, rivers and towns. The **seed** is a number: the same seed and settings always make the same world, and **New seed** tries another. Choose how much **land**, how **rugged** it is, the **climate** (cold, temperate or warm), and whether to add rivers, symbols and names. On an existing map it replaces everything painted and placed on it, and **Ctrl+Z undoes it**; the map keeps its size, scale and art style. Everything it makes is ordinary map content you can keep editing, moving, renaming or deleting.

**Seasons and eras.** The **season** box in the toolbar shows the same map in spring, summer, autumn or winter: the grass, forests and fields turn fresh, golden, orange and red, or white with snow, and lakes and shallow seas freeze over in winter (in every art style; "Any season" leaves the style as it is). The **Year** box shows the map as it was in one year, for a history of kingdoms, cities and roads: select a symbol, line or region and choose **Years it exists...** (right-click) to say from which year and until which year it exists (an empty box means no limit; it applies to everything selected). Tick **Year** and type a year and only the things that exist in that year are drawn, listed in the legend and selectable, in the players' view, the exported picture and the thumbnails too. Untick it to see and edit everything again. The painting itself (coasts, land, rivers painted as land) does not change between years; only the placed things do.

**Snapping.** While you drag symbols, labels and banners with the Select tool, their left edge, middle and right edge snap to the map's left, middle and right (and top, middle and bottom to the map's top, middle and bottom) when they come close, and a red dashed guide line shows what they snapped to. Handy for centring a title. The magnet button in the toolbar turns snapping on and off (it is remembered), and holding **Alt** while you drag moves freely for that drag.

**Changing the size afterwards.** Made the map too big (or too small)? The **Map size** button (next to Fit) changes it at any time, and **Ctrl+Z undoes it**. **Scale the whole map** to a new width: the painting, symbols, lines, regions and the legend all shrink or grow with it. **Crop or extend the canvas** adds blank margins on any side, or cuts them off with a negative number, without changing the size of anything on it (symbols that end up outside are removed, and it tells you how many first). Either way you can also set how many **miles across** the map is; that only changes the distances (scale bar, ruler, travel times), not the picture. Maps can be from 64 x 48 up to 4096 x 3072 cells.

**Showing it to your players.** Three things keep your secrets safe. (1) **Hide from players**: select a symbol, line or region and press the crossed-eye button (or **H**, or right-click it and choose **Hide from players**). You still see it, faded; the players never do, and it is left out of their legend too. Do it again to show it. (2) **Hide unexplored**: the cloud button covers the whole map with blank parchment for the players, and the **Reveal** tool uncovers what they have found: drag to reveal, hold **Alt** to cover again (or use the **Reveal / Cover** switch), and **Reveal all** / **Cover all** do the whole map at once. You see the unexplored area faintly covered, so you can still read your own map. Things standing in unexplored areas are not in the players' legend either. (3) **Player view** (the monitor button) opens a separate window for the players' screen with its own zoom and pan (scroll, drag, **F** fit, **G** grid, **F11** full screen). It keeps up with everything you do. Notes, links, the ruler and selection marks are never shown there.

**Export image.** The picture button saves the map as a PNG: choose the **DM's version** (everything, with hidden things faded) or the **players' version** (exactly what the player window shows), a width from 1024 to 8192 pixels, and whether to include the grid and the scale bar and legend. Big pictures are drawn in strips, so they do not use much memory, and a progress window lets you cancel.

## Relationships and family trees
Every card has a **Relationships** section at the bottom. Add a line for each person it is connected to: **parent of, child of, spouse or partner of, sibling of, mentor of, student of, employer of, works for, ally of, rival or enemy of, or connected to** (with a note such as "owes him a favour"). You only have to enter a relationship on one of the two cards: the other card shows it too ("Child of Dan - set on their card"), and entering it on both counts once. Press **Relations...** in the top bar to see them as pictures:

- **Family tree:** parents, partners, siblings and children laid out in generations, with partners side by side and children centred under their parents. Several separate families sit side by side.
- **Web of relationships:** allies, rivals, mentors (arrows from mentor to student), employers and other connections, drawn as coloured, labelled lines.
- **Organisation hierarchy:** just the chains of command: every organisation with members is drawn with the group at the top, its leaders beneath it and the people who report to them below, side by side. Use **Show** to look at one organisation. Click a box to open that person or group.
- **Everything:** one big map of the whole campaign: the family ties, the web of relationships and your **organisations** with their members and chains of command, all together. Like the family tree and the hierarchy it runs **top-down**: whoever is above someone (a parent, mentor, employer, boss, or an organisation over its members) is higher up, with arrows pointing down to the child, student, employee or person who reports to them; every link has a **label** saying what it is ("parent of", "rival (since school)", "reports to", a member's role...); partners have a double line, siblings a dashed one; an organisation is joined to its members (and to its leaders in purple, with each member's role as the label), and orange arrows run from a boss to the people who report to them. Tick or untick **Family**, **Relationships** and **Organisations** to show only some kinds of link. People and groups with no links at all are left out.
- **Show** one card (or, on the Everything tab, one organisation) to see just the family, web or group it belongs to. Click anyone to open their card. Relationship notes are included in project search.
- Duplicating a card does not copy its relationships, since the copy is a different person.

## Spell cards
Spells are their own item type (**+ Spell** in the project tree, saved as `spells/<id>.spell`), so you can write your own homebrew spells and keep spells you use often in the project. **Range / target**, casting time and duration are dropdowns of the usual choices (Self, Self (15-foot cone), Touch, Sight, 30 feet, 60 feet... for range; 1 action, 1 bonus action, 1 minute... for casting time; Instantaneous, 1 minute, 1 hour... for duration) that also take anything you type, so a custom value is always possible. A spell card has name, level (cantrip to 9th), school, casting time, range, components (V, S, M and what the material is), duration, concentration, ritual, classes, description, "At higher levels" and your own notes, with a spell card that updates live beside the form. Spells imported from the SRD (see the Library below) become spell cards with **Add as spell card**; duplicate one to make a homebrew variant. Spell cards can be linked and previewed like any other item and are found by project search (name, text, class, school, material, notes).

## Magic items
Magic items are their own item type (**+ Item** in the project tree, saved as `items/<id>.item`), so a homebrew item or a piece of loot can be written once and linked from anywhere. An item has a name, type (wondrous item, weapon, armor, potion, ring, wand...), rarity (common to artifact), whether it needs attunement (and by whom), a description, charges and when they come back, a curse or drawback, its value in gold and your own notes. The card beside the form updates live and takes its accent colour from the rarity. Items can be linked and previewed on hover like any other item, are offered by name hints when their name appears in text, and are found by project search (name, description, curse, notes).

## Organisations

An **organisation** is a group of characters: a thieves' guild, a noble house, a temple, the player party, a villain's gang. Make one with **+ Organisation** in the project tree (the shield with a plus; saved as `organisations/<id>.organisation`). It has a name, a **type** (typed freely, for example "Thieves' guild"), where it is **based**, a **summary**, what it **wants**, and your own notes. A summary beside the form updates live.

The **Members** list holds the group's people. Press **+ Add member...** and pick player characters, NPCs, monsters or other organisations (a guild can have a rival guild or a branch as a member); **Ctrl-click or Shift-click to pick several at once**, and the same works in the other "add" lists: what a quest **involves**, what came up in a session, and **+ From my cards...** in an encounter; give each one a **role** such as "Leader" or "Spy". Under each member, **reports to** lets you say who they answer to (another member of the group): that builds the **chain of command**, drawn on the **Hierarchy** tab on the right of the organisation like a family tree, with the group at the top, the people who report to nobody beneath it and each person's reports beneath them (click a box to open it). The **Members** list sorts itself the same way: the people at the top of the group first, then those who report to them, indented under them, and so on down, and it re-sorts as soon as you change a "reports to". Nobody can report to someone beneath them, and if a member is removed the people who reported to them move up one. **Double-click a member** (its name, shown as a link, or its icon), or press **Open**, to open its card in a tab; **hover** it for a preview of the card. **✕** takes a member out of the group without touching the card. A card can belong to as many organisations as you like, and deleting an organisation never deletes its cards; if a member's card is deleted it shows as "(deleted item)" until you remove it.

Organisations are found by project search (name, type, base, goals, summary, notes, member names and roles), can be linked and previewed on hover like any other item, copied with **Duplicate**, and exported or printed as Markdown like cards and quests.

## Quests
Quests are their own item type (**+ Quest** in the project tree, saved as `quests/<id>.quest`) for plot threads you want to keep track of. A quest has a name, a status (open, active, on hold, done, failed), who gave it (type a name, or press **Choose...** to pick one of your characters: the name then shows as a link, **hover** it for the character card and **double-click** it to open the card; it follows the card if you rename it, and **Clear** goes back to typing), the reward, a summary, a checklist of **steps and clues** to tick off as the party does or finds them, the characters, maps, whiteboards and items it **involves** (add them, double-click to open), and your own notes. A summary beside the form updates live. Press **Quests...** in the top bar for the **quest board**: every quest in columns by status with its progress ("1 of 3 steps") and giver, a filter box, double-click to open and right-click to move a quest to another status. Quests can be linked and previewed on hover like any other item and are found by project search (name, summary, steps, giver, reward, notes).

## Sessions and the timeline
Each game session can have its own page (**+ Session** in the project tree, saved as `sessions/<id>.session`). A session has a title, a number, the real date you played, the date in the game world (as you write it, for example "14th of Mirtul, 1492") and an optional **campaign day** number so the app can show time passing, then a **recap for next time**, what happened, next steps, and the characters, quests and maps that came up. A new session starts with the next number, today's date and the previous session's campaign day. When you open a session, a box at the top shows **"Last time on..."**: the recap of the session before it, with how many days later this one is, a **Copy** button and a button to open that session. Press **Timeline...** in the top bar to see every session in order with its dates, the days that passed between them and its recap; click one to open it. Sessions can be linked and previewed on hover like any other item and are found by project search (title, recap, what happened, next steps).

## Links and notes in text
On a whiteboard, links and notes work on **selected words**, not just whole text blocks:

- **Link a few words:** double-click a text block or sticky note to edit it, select the words (a character name in the middle of a paragraph, say), then press **Link...** (or Ctrl+K) and pick the target. Only those words become a link: blue and underlined. **Hover** a link and a small preview of what it points to appears next to the pointer: a character or monster stat block, a spell card, a battlemap thumbnail, an encounter's creatures and difficulty, or the first lines of a whiteboard. **Double-click** it to open the target. Turn off **Link previews** (the eye icon) in the whiteboard toolbar if you would rather not see previews; the choice is remembered. In the text you will see the words wrapped like `[Mira]{1}` while you edit (just as bold shows as `**bold**`); the target is kept with the note, so deleting the brackets undoes it.
- **A note on a few words:** for things that have no sheet of their own (a rumour, what the innkeeper is hiding, a house rule), select words and press **Note...**, then type your own text. It can use `**bold**` and `*italic*` and run over several lines. The words turn green and underlined; **hover** them and the note appears in a small green-edged box. To change it later, **double-click** the words (or right-click them and choose **Edit note on these words...**). Right-click also has **Remove note from these words**.
- **Both on the same words:** a link and a note can share a selection. They show blue with a small green dot; hovering shows the note above the preview, and double-click still opens the link (edit the note from the right-click menu or with **Note...** while typing).
- **Whole objects:** with an object selected (not typing), **Link...** and **Note...** apply to the whole thing, for text blocks, pictures and shapes; a note shows as a green "i" badge next to the blue link badge. Right-click an object for the same options (**Edit note...**, **Remove note**). Double-click a shape or picture that only has a note to edit it.
- **Remove:** select the words (or the object) and press **Unlink** or **No note**.
- Whiteboards that link to an item show up in that item's **Backlinks** (notes are not links, so they do not). Project search also finds text inside notes.

### Name hints
When the name of one of your cards, spell cards, magic items or organisations appears in a block of text, it gets a faint dotted underline. Hover it and a small box offers **Link** (the words become a link to that card, which then previews it on hover) or **Dismiss** (stop underlining that name in that text block; other blocks are unaffected). Names are matched as whole words, ignoring case, longest name first (so "Mira Stonehelm" wins over "Mira"), and card names under three letters are ignored (aliases can be two). **Aliases:** a card's name is matched in full, so "Jasper" alone does not match a card called "Jasper Egan". Give the card **Also known as** names (for example `Jasper, Jas, Captain Egan`, separated by commas, at least two letters each, so initials like JE work) in its Identity section, and any of those words now offers the same link. The hint box shows which card it means ("Jasper -> Jasper Egan"). A card's real name always wins if an alias clashes with another card's name, and a duplicate card does not copy the aliases. Aliases are also found by project search. Words that already have a link or note are left alone. Press **Link all names** in the whiteboard toolbar to link every suggested name at once: in the selected text blocks and sticky notes, or on the whole whiteboard if nothing is selected (one undo step; names you dismissed are left alone). Turn off **Name hints** (the underlined-A icon) in the whiteboard toolbar to switch the underlines off; the choice is remembered.

## Cards (characters and monsters)
Cards are their own item type (`+ Card` in the project tree, saved as `cards/<id>.card`). Each is a 5e-style stat block: name, kind (player / NPC / monster), size, type, alignment, AC, HP and hit dice, speed, the six ability scores (with live modifiers), saves, skills, resistances, senses, languages, CR/XP, initiative bonus, a portrait, traits, **attacks** (to-hit, damage dice, type, reach/range, extra effect), other actions, reactions, legendary actions and notes. A parchment-style stat block updates live beside the form.

- **Start from a template:** a blank player character, a blank creature, or one of ten example creatures (goblin, kobold, skeleton, zombie, wolf, giant rat, orc, bandit, guard, commoner).
- **Duplicate** a card from the tree's right-click menu to make variants. Any whiteboard text or object can be **linked** to a card, so a double-click opens its stat block.

## Encounters
An encounter is a saved fight, its own item type next to whiteboards, battlemaps and cards (`encounters/<id>.encounter` in your project folder).

- **Create one:** **+ Encounter** in the project tree (or right-click > New encounter). Duplicate it from the right-click menu to make variants.
- **Build it:** pick a **common enemy** (goblin, orc, wolf...) from the dropdown, or use **+ From my cards...** for player characters, NPCs and your own custom cards. For each one set how many, which side (enemy / ally / player) and whether they act as a group.
- **Common enemies:** a shelf of creatures shared by every project, so you do not need a card in the project to use a goblin. **Edit common enemies...** opens the library: change any creature's stats, remove ones you never use, add homebrew creatures (blank, duplicated, or copied from one of your project's cards), or restore the starter creatures. They are also listed in the battle's **+ Add creatures...** dialog. The first time one is used in a project a card for it is made in a "Common Enemies" folder, and it is refreshed from the library each time it is used (to change a creature for one project only, duplicate its card). The library is stored in `Common Enemies` next to your projects.
- **Difficulty:** set your party (number of characters and their level; it is remembered with the project) and the encounter shows **Trivial / Easy / Medium / Hard / Deadly**, using the 5e Dungeon Master's Guide method (monster XP, times the multiplier for how many enemies there are, against the party's XP budget). Only enemies count. XP comes from each card's XP, or from its challenge rating if XP is blank.
- **Treasure:** the **Treasure** section rolls loot for the fight from the enemies' challenge ratings: **A creature's pockets** gives every enemy some coin at its own level (one result per level), **A treasure hoard** rolls one stash at the level of the strongest enemy. Press **Roll treasure** again for something different, edit the text freely (it is saved with the encounter), **Copy** it, or **Add to a session...** to append it to a session's notes. Only enemies count, like the difficulty.
- **Run it:** on a battlemap press **Battle**, then **Load encounter...** in the setup screen to add all its creatures (and their tokens) in one go, then enter initiative and Start.
- Like any item, an encounter can be linked from a whiteboard object (it opens on double-click).

## Battle mode
On a battlemap, press **Battle** in the toolbar to open the battle screen. The map stays in the middle; creature cards go on the right and the turn order runs along the bottom. Combat is tracked by hand: you roll the dice and type the results; the app keeps the state. A slate banner at the top says **Battle setup**; once the fight starts it turns amber and reads **BATTLE - Round N** with whose turn it is.

**1. Set up (once).** **+ Add creatures...** picks cards from your project: tick each creature, set how many, which side (player / ally / enemy) and whether they **act as a group**. Type each creature's initiative, or press its **d20** button; **Roll enemies and allies** rolls everyone who has none yet (one roll per group). Players roll their own, so type their results in. **Start battle** stays locked until everyone has an initiative, and initiative is never rolled again afterwards.

**2. Run it.** The **initiative strip** along the bottom lists everyone in order. The creature whose turn it is gets a large amber chip and the strip scrolls to it. Press **Next >** (or **N**) to advance, **< Back** (or **P**) to step back. Defeated creatures are skipped and a new round starts after the last one. The active creature's **large card** is on the right with its attacks (to-hit, reach/range, damage with average), traits and full stat block.

**3. Plan ahead.** Click any chip in the strip, or any token on the map, to show that creature in a second card under the active one, without changing whose turn it is. **Back to current turn** closes it. Late arrivals can be added mid-battle with **+ Add creatures...** and are asked for their initiative.

**HP:** every card has an HP bar and a box: type `-7` for damage, `+5` to heal, or a plain number to set HP. **Several hits at once** work too, e.g. `-5 -7 -3`. Temporary HP soak damage first, reaching 0 marks a creature down (its token greys out with a cross), and healing brings it back. The `...` menu has rename, max HP, temp HP, AC, **conditions**, notes, find token, **place token** (if you deleted the old one) and remove. **Conditions** show as a coloured ring around the creature's token, split into one slice per condition (Poisoned is green, Stunned yellow, Frightened purple, and so on), on your map and in the player window, and as matching dots on its chip in the initiative strip. **Death saves.** A player character reduced to 0 HP falls unconscious and is **dying** instead of simply down: its card shows three success and three failure marks with **Roll death save** (a d20: 10 or more succeeds, 1 counts as two failures, 20 brings it back with 1 HP), **+ Success**, **+ Failure** and **Stabilise**, and its chip in the initiative strip gets a skull. Damage at 0 HP is a failure; damage that leaves at least the creature's maximum HP over kills it outright. Three successes make it stable (it takes no turns until healed), three failures kill it, and any healing brings it back and clears the saves. Monsters just go down at 0, but the `...` menu has **Makes death saves at 0 HP** to turn it on for a villain (or off for a player). **Concentration.** Choose **Concentrating on...** in the `...` menu (or tick Concentrating in Conditions) and the card shows it with a **Drop** button. When that creature takes damage you are asked whether it passed the Constitution save (DC 10 or half the damage, whichever is higher); answering Failed ends it. Falling unconscious ends it too. **Effects and counters.** **Add effect...** puts a named effect (Hunter's Mark, Slowed) on a creature for a number of its own turns; it counts down when that creature's turn ends, disappears by itself, and can be clicked to end it early. **Reaction used** is a tick that clears at the start of the creature's turn, and creatures with legendary actions get a counter (3 by default, change it in the `...` menu) that resets at the start of their turn. All of this is saved with the battle. **Map tools** in the banner brings the normal toolbar back for moving tokens and revealing fog; **Exit** returns to the normal editor and keeps the battle.

**Quick map tools in battle:** a **Map:** strip under the banner (during setup and during the fight) has **Move**, **Ruler**, **Area** and **Pin** buttons, so you can measure a distance, lay a cone or circle over the map, or drop a private note without opening the map toolbar. Choosing Area shows its shape and size right there. One switch, **Show ruler and area to players**, draws whatever you have laid on the map in the player window too (off by default, so you can plan privately), and **Clear** takes the ruler and area off the map. Pins are never shown to the players.

**Groups:** creatures that share a group take one turn together with one initiative (a pack of goblins). Tick two or more rows in setup and press *Group*, or *Ungroup* later. The card lists each member with its own HP.

The **player window** (Pop out) shows a slim turn-order strip along the top: names only, never HP, and it leaves out hidden creatures and enemies still in the fog. Press **I** there to show or hide it. The token whose turn it is gets a gold ring on the map and in the player window.

## Fog of war
Tick **Fog** in a battlemap's toolbar to hide the map from the players until you reveal it. The player window shows unrevealed cells as solid black (so enemies and pieces under fog are not visible); in your editor the fog is shaded but see-through.

- **Fog tool** (key 7): choose *Reveal brush*, *Hide brush*, *Reveal rectangle* or *Hide rectangle* in the Fog list, then click or drag. The brush uses the same size box as terrain. *Reveal all* / *Hide all* act on the whole map.
- **Auto-reveal:** tokens set to reveal fog (players' tokens by default; right-click a token > *Reveals fog around it* to choose 3, 6, 9 or 12 cells) clear the fog around them as you place or move them. Explored cells stay revealed.
- **Hidden from players:** right-click a piece or token > *Hide from players* for traps, secret doors or an ambush. You still see it (ghosted); the players never do, even in revealed areas.
- Fog and reveals are part of undo (Ctrl+Z) and are saved with the map.

## Name generator
Click **Names...** in the top bar (or press Ctrl+G), pick a race and optionally a gender, and it rolls first + last names. Select one and hit **Copy**, or **Add to board** (or double-click a name) to drop it onto the current whiteboard as text. Races: Human, Elf, Dwarf, Halfling, Gnome, Half-Elf, Half-Orc, Tiefling, Dragonborn, Orc, Goblin, Tabaxi, Aasimar, Genasi, Goliath, Kobold and Tortle.

## Monster and spell library
Press **Library...** in the top bar to browse the 5e SRD monsters and spells. The data is not bundled with the app: download [5e-SRD-Monsters.json](https://raw.githubusercontent.com/5e-bits/5e-database/main/src/2014/en/5e-SRD-Monsters.json) and [5e-SRD-Spells.json](https://raw.githubusercontent.com/5e-bits/5e-database/main/src/2014/en/5e-SRD-Spells.json) once from the open [5e-database](https://github.com/5e-bits/5e-database/tree/main/src/2014/en) project (the library window has links too; your browser shows the text, so press Ctrl+S to save it) and press **Import SRD file...** in the library window (you can pick both files at once). The imported data is kept next to your projects in `SRD Library`, so every project can use it.

- **Monsters:** search by name and filter by type or challenge rating. The full stat block is shown. **Add to project as a card** makes an ordinary, editable card in an "SRD Monsters" folder (its attacks are filled in, so it works in battles straight away). **Add to common enemies** puts it in the dropdown used by the encounter builder and the battle's Add dialog, in every project.
- **Spells:** search by name and filter by level, class and school. **Add as spell card** turns the spell into an editable spell card in your project (in a "Spells" folder; if you already made one from that spell it opens that one instead). **Add to board** puts the spell on the open whiteboard as a text note, and **Copy** copies it.
- Importing a file again replaces what was imported before for that kind (monsters or spells).

## Settings

The **gear** button in the top bar (also on the project list, and **Ctrl+,**) opens the settings of the whole app, not of one campaign. Changes apply at once and are kept in `settings.properties` in your CampaignPocketbook folder.

- **Appearance:** **Text size** from 80% to 200% makes the text and buttons of every window bigger or smaller (the open campaign and its tabs come back as they were; whiteboards and maps keep their own zoom, and printing is never scaled). **Font** lets you choose an installed font; fonts that are easier to read, such as OpenDyslexic, Atkinson Hyperlegible or Lexend, appear in the list when they are installed on your computer (the app cannot include them). **Colours** switches light and dark mode.
- **General:** how soon changes are saved (the default is a second after you stop), how many steps undo remembers, **backups** (make one when you close a campaign, how many to keep, open the folder), whether to **open the campaign you used last time** straight away, whether to **look for a newer version** when the app starts (turn it off if you work offline; **Show a dismissed update again** brings the blue bar back), whether to **ask before deleting** an item from the project tree (a backup is made either way) and how quickly the preview of a link or note appears when the mouse rests on it.
- **Maps & new things:** how new things **start**: the art style, size and miles across of a new world map, the grid and size of a new battlemap, the party size and level of a new campaign, and the text size and colours of a new whiteboard. Nothing that already exists changes. Also **distances on world maps in miles or kilometres** (the scale bar, ruler and status line; the boxes that ask for a size still ask for miles) and **how many hours of travel make a day**.
- **Player windows:** open them full screen, hide the hint about dragging the window to the playtable screen, and show the turn-order strip by default.
- **Accessibility:** **High contrast** (black on white, or white on black in dark mode) with heavy outlines and a strong focus ring. **Colour-blind-safe colours** change the condition colours to ones that stay apart for the common kinds of colour blindness and write a two-letter code (Po for Poisoned, Pr for Prone...) on the ring around a token and in the turn order, so colour is never the only clue. **Reduce motion** stops the turn order gliding and the fading hint in the player window. **Hints on buttons** can appear fast, normally or slowly. Everything in the app can be done with the keyboard, and every key can be changed. Maps and whiteboards are pictures, which a screen reader cannot read.
- **Shortcuts:** see Keyboard shortcuts above.
- **Data & updates:** open the folder where your campaigns are kept, save all settings (including shortcuts) to a file and load them on another computer, or reset everything to the defaults. Every tab also has its own **Reset this tab** button.

## Quick reference

The **Rules...** button in the top bar (or **Ctrl+R**, or the page button on the battle screen) opens a small window with the rules a DM looks up most, written in plain words as a memory aid: all the conditions, concentration, death saves, grappling, cover, light and vision, travel pace, resting, falling, suffocation and more. Search it, or pick from the list. In a battle, **hover a condition** on a creature to read its rule, and click it to open the full entry.

## Exporting and printing

Right-click an item in the project tree:

- **Export as Markdown...** (character and monster cards, spells, magic items, quests, session logs and encounters) saves a plain `.md` file you can open in any notes app, wiki or word processor: stat blocks as a table of abilities with traits and actions, quests as a checklist, sessions with their recap and next steps, encounters with their treasure.
- **Print...** (the same kinds of item) opens your system's print dialog and prints the item as a clean page in the light colours, whatever mode the app is in. A long stat block continues on more pages. To get a PDF, choose a PDF printer in the print dialog ("Microsoft Print to PDF" on Windows, "Save as PDF" on macOS and most Linux systems).
- **Export image...** saves a **battlemap** (the DM's version or the players' version, 1024 to 8192 pixels wide, with or without the grid), a **world map** (see World maps) or a **whiteboard** (everything on it, at up to twice the size) as a PNG. Large pictures are drawn in strips with a progress window, so they do not use much memory.

To print a map or a whiteboard, export the picture and print that.

## Loot generator
Press **Loot...** in the top bar (or **Ctrl+L**) for random treasure. Pick a **tier** (the challenge rating of what the party beat: 0-4, 5-10, 11-16, 17+) and either **a creature's pockets** (coins and the odd keepsake; set how many creatures and the coins are added together) or **a treasure hoard** (coins, gems, art objects, magic items of rarities that suit the tier, and a few curios). It changes as you change the options, **Roll** rolls again, **Copy** copies it and **Add to board** puts it on the open whiteboard as a text note. The amounts are rough guidance in the spirit of the usual treasure tiers, not a published table, so change anything you like.

## Dark mode
Press the **moon icon** in the top bar (or on the project chooser) to switch the whole app to a dark theme, and the **sun icon** to switch back. It is remembered the next time you start the app (in `settings.properties` next to your projects) and applies to every window and dialog. On whiteboards the board turns dark and dark text and lines are drawn lighter so they stay readable; the colours stored in your notes are never changed, and sticky notes, images and stat blocks keep their own colours. The player window is always dark.

## NPC generator
When the party talks to someone you had not planned, press **NPC...** in the top bar (or **Ctrl+Shift+N**). Pin whatever you care about, leave the rest on **Random**, and press **Roll**: race, gender, **category and profession** (over 60 built in, from farmers and innkeepers to guards, priests, nobles and thieves), age group and attitude to the party (friendly, neutral, wary or hostile). You get a name that fits the race, an age, two details of appearance, two personality traits (which lean warm or cold with the attitude), a mannerism, a voice, what they want, a secret, what they open with, and a couple of things a person in that job might know or offer, which is handy for improvising the conversation.

- **Re-roll one detail:** the small button beside each line rolls only that line and keeps the rest (and keeps what you pinned).
- **You choose what happens to them.** Rolling only shows the NPC. **Add to board** puts the description on the open whiteboard as a note, **Save as NPC card** makes a card in an "NPCs" folder (stats borrowed from a matching creature, e.g. a guard gets guard stats, with the description in its notes, ready for a battle), and **Copy** copies the text. Each does only its own thing, so you can add one to the board without creating a card.
- **Your own professions:** **Edit professions...** lets you add professions (name, category, which creature's stats suit them, and what they might know). They appear next to the built-in ones in every project; the built-in ones cannot be changed. They are stored in `npc-professions.json` next to your projects.

## Backing up and sharing a campaign
On the first screen (the project list) the campaign you opened most recently is at the top, then the others in the order you last opened them (campaigns you have not opened on this computer yet follow, A to Z). Select a campaign and press **Export backup...** to save the whole thing (whiteboards, maps, cards, spells, items, quests, sessions, encounters, pictures and imported map pieces) as one `.zip` file. Press **Import backup...** and choose such a file to bring a campaign in, on the same computer after a mishap or on another one. An import always becomes a **new project** (a name that is already taken gets "(2)" and so on), so nothing you already have is ever overwritten, and a file that is not a campaign backup or tries to write outside its own folder is refused. The SRD library and your other settings are shared by all campaigns and are not part of a backup.

**Automatic safety copies:** you do not have to remember to back up. When you close a campaign (or the app) after changing it, and just before you delete anything, the app saves a backup zip of the whole campaign into `~/CampaignPocketbook/.backups/<campaign name>/` and keeps the newest five. To go back, press **Import backup...** on the project list (it opens in that folder) and pick one; it comes back as a new campaign, so nothing is overwritten. If an item's file is ever damaged, the app tells you which file, leaves it untouched, and the rest of the campaign still opens.

## Organising your project
- **Icons:** the project tree and the tabs show a small drawn icon for each kind of item: a folder (it opens when expanded), a whiteboard, a battlemap, a card, a spell (book with a sparkle), a magic item (gem), a quest (banner), a session (calendar page) and an encounter (crossed swords). Folders show how many items are inside them, for example `NPCs (7)`.
- **Colours:** right-click any folder or item and choose **Set colour** to pick from ten colours (or **Default colour** to go back). The icon takes the colour in the tree and on the item's tab, so you can spot your NPCs, your maps or the current session's folder at a glance.
- **Keyboard:** with the project tree selected, **F2** renames the selected item and **Delete** deletes it (with the usual confirmation). Delete only touches the tree item here, never the open whiteboard.
- **Tabs:** right-click a tab for **Close**, **Close others**, **Close all** and **Reveal in tree**.
- **Recent:** **History > Recent** in the top bar lists the last ten items you opened, newest first, for jumping back quickly.

## For developers
**Versions** are `1.y.z`. The `1` only changes if there is ever a second generation of the app; `y` goes up for every new feature (and `z` resets to 0); `z` goes up for a fix or small change. The version lives in `pom.xml`.

**Branches.** The app's update banner reads the version in `pom.xml` on `main`, so everything that is pushed to `main` is a release. Day-to-day work happens on the `dev` branch (push it as often as you like, nobody is told about it); when a set of changes is ready, merge `dev` into `main` and push, and that is when users see the banner:
```
git checkout main
git merge dev
git push
git checkout dev
```

```
mvn test           # run the unit tests
mvn javafx:run     # run the app
```
Source is in `src/main/java/dnd/` (`model`, `storage`, `ui`, `nav`, `search`, `map`, `names`, `update`).

The world map symbols are generated too: each symbol is one short Python function in `tools/world-assets/` (`features_land.py`, `features_misc.py`, `features_settlements.py`, `features_decor.py`, helpers in `worldlib.py`) that takes an art style, so adding a symbol adds it in all five styles. Run `python build.py` in that folder to rewrite `src/main/resources/assets/world/` and `world-index.json`.

The battlemap SVG pieces are generated by a small Python script, so they can be tweaked or extended in one place. Each piece is a short function in `tools/svg-assets/` (`buildings.py`, `walls.py`, `paths.py`, `camp.py`, `nature.py`, `dungeon.py`, `furniture.py`) built on shared helpers in `svglib.py` (shingles, stonework, planks, shadows, grain, gradients). To change or add pieces, edit those files and run:
```
cd tools/svg-assets
python build.py
```
That rewrites `src/main/resources/assets/` (the SVGs and `index.json`). Keep existing piece ids and sizes unchanged so older maps still load.
